# R-03 · A complete Todo agent in React

This fixture keeps a normal React Todo component and adds only the declarations
needed for a working page agent: one scope, one record per row, and three named
controls. The assistant uses the same state setters as the visible UI.

```bash
pnpm tutorial:dev r-03
pnpm tutorial:dev r-03 --locale zh
pnpm tutorial:check r-03
```
