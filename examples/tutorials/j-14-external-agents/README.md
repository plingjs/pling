# J-14 · Expose selected capabilities to external agents

The page keeps its normal human controls and exposes a deliberately smaller
surface to an external client. The external console can describe the bounded
capability set, add a task, and request a destructive clear that still requires
confirmation on the page.

```bash
pnpm tutorial:dev j-14
pnpm tutorial:dev j-14 --locale zh
pnpm tutorial:check j-14
```
