This fixture keeps the V3-16 order flow and focuses on the runtime around it:
explicit limits, a bounded request trace in the Activity view, and stable error
codes for failed actions and flows.

Run it with `pnpm tutorial:dev v3-17`; the page is served at
`http://127.0.0.1:5230/`.
