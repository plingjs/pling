# V2-02 · Install and first mount

This fixture keeps a plain Vue 2.7 application and adds one `createPling()` call,
`Vue.use(pling.plugin)`, and the shared assistant dock. It deliberately exposes
no page actions.

```bash
pnpm tutorial:dev v2-02
pnpm tutorial:dev v2-02 --locale zh
pnpm tutorial:check v2-02
```
