# V3-14 · Feedback, target highlighting, and human guidance

This fixture adds a workspace release form to the Todo example. Invalid input appears as structured `v-feedback`; the verification-code field is marked with `v-guide-target` but is not an agent action; the publish action declares a two-step handoff and uses spotlight presence.

From the repository root:

```bash
pnpm tutorial:dev v3-14
```

The example runs on port `5227` after packing and installing local framework tarballs. Run deterministic checks with:

```bash
pnpm tutorial:check v3-14
```
