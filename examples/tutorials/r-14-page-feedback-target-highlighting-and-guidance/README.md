# R-14 · Page feedback, target highlighting, and guidance

This fixture starts from R-13. The Todo app keeps its assistant surface and adds
a release panel. A failed save or publish becomes read-only page feedback. The
verification-code field is a guide target rather than an action, and the publish
action uses a human handoff with step-by-step highlighting.

```bash
pnpm tutorial:dev r-14
pnpm tutorial:dev r-14 --locale zh
pnpm tutorial:check r-14
```
