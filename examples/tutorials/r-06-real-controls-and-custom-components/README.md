# R-06 · Real controls and custom components

This fixture starts from the working Todo agent in R-05. The business operation
stays the same, while the page adds a native priority selector, a custom search
field, a component with several filter buttons, and a hover-opened menu. The
chapter focuses on which DOM element receives each interaction.
