# Vue 2.7 recipe lab

This is the Vue 2.7 implementation of the shared order-desk recipe lab. It covers form validation,
confirmation for dangerous actions, search and long lists, continuity, state exposure, and a
host-owned connection form for model access.

```bash
pnpm --filter @plingjs/recipe-vue2 dev
```

Open `http://localhost:5233/` for English or `http://localhost:5233/?lang=zh` for Chinese.
See [`../README.md`](../README.md) for the shared scenario and the other adapters.
