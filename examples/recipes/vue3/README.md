# Vue 3 recipe lab

This is the Vue 3 implementation of the shared order-desk recipe lab. It covers form validation,
confirmation for dangerous actions, search and long lists, continuity, state exposure, and the
built-in model settings panel.

```bash
pnpm --filter @plingjs/recipe-vue3 dev
```

Open `http://localhost:5230/` for English or `http://localhost:5230/?lang=zh` for Chinese.
See [`../README.md`](../README.md) for the shared scenario and the other adapters.
