# React recipe lab

This is the React implementation of the shared order-desk recipe lab. It covers form validation,
confirmation for dangerous actions, search and long lists, continuity, state exposure, and a
host-owned connection form for model access.

```bash
pnpm --filter @plingjs/recipe-react dev
```

Open `http://localhost:5231/` for English or `http://localhost:5231/?lang=zh` for Chinese.
See [`../README.md`](../README.md) for the shared scenario and the other adapters.
