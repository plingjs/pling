# 采用证据与案例

这一页记录目前可用的采用证据，以及这些证据能够支持的结论边界。仓库中还没有独立的生产部署案例。参考应用、教程夹具和已鉴权 Surface 演示能证明行为可运行，不能证明市场采用。

## 当前证据

| 产物 | 证明什么 | 不证明什么 |
| --- | --- | --- |
| 教程示例 | 文档 API 能在受控应用里运行 | 生产使用或客户价值 |
| Surface 与 MCP 案例 | 页面能把有界能力面开放给外部客户端 | 通用传输或企业身份部署 |
| 已鉴权 Todo 案例 | 页面、BFF 与网关能隔离凭证并要求真人审批 | 多租户生产规模或独立安全评审 |
| 基准报告 | 一个夹具与模型上的冻结比较 | 广泛优越性或采用 |

## 如何公开案例

可信案例应在获得许可后说明组织、页面类型、暴露能力、身份与审批路径，以及测量到的运营结果，并写清没有测量什么。移除客户数据、凭证和包含个人信息的截图。

有用指标包括按明确完成 oracle 计算的任务成功率、完成时间、人工介入次数、错误类别和接入成本。Token 数本身不是业务结果；更短但没完成任务的运行仍是失败。

## 什么才算采用

项目需要一个无关联生产站点使用协议，并证明 Surface 断开时业务页面仍正常、撤销 Agent 在执行前失效、声明的危险动作确实需要真人批准。第二个独立客户端实现会加强互操作声明。

在此之前，诚实描述是“参考实现与初步证据”。不要把演示部署、教程或合成基准变成客户 logo。

## 欢迎评审

如果你运营站点并想评估这条路径，从一项只读能力、一项有界写入和一项带审批的危险能力开始，先记录失败，再扩大范围。最有价值的贡献是可复现的否定结果，而不是省略来路的成功故事。
